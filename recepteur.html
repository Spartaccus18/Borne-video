Réception des vidéos de la borne

Cette page reçoit les vidéos de l'iPad par le réseau local et les écrit directement dans le dossier de votre choix (par exemple le SSD). Rien ne passe par internet. Il faut Chrome (ou Edge) sur ordinateur.

Navigateur non adapté

Ce navigateur ne peut pas écrire dans un dossier. Ouvrez cette page dans Google Chrome ou Microsoft Edge sur le Mac.

1. Choisir le dossier de destination

Les vidéos seront rangées dans un sous-dossier par candidat. Les fichiers déjà reçus en entier sont reconnus et ne sont pas renvoyés.

Aucun dossier choisi

2. Coller le code de l'iPad

Sur l'iPad (menu organisateur › « Envoyer au Mac ») : « Préparer la connexion », « Copier le code », puis collez-le ici (le presse-papiers partagé Mac/iPad le fait passer tout seul si les deux sont connectés au même compte Apple, sinon envoyez-le par AirDrop ou Messages).

3. Renvoyer ce code à l'iPad

Sur l'iPad, collez-le dans « Code de réponse du Mac », puis touchez « Connecter ».
